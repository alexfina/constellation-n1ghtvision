# Project Brief

## Goal

Build a small, deterministic JavaScript web app that recommends movies, TV shows, or anime from local data.

## Scope

- Beginner-friendly frontend learning project
- Local JSON-based recommendation data
- Simple filtering and selection logic
- Minimal UI with a constellation / starfield reveal

## Non-Goals

- No backend
- No user accounts
- No database server
- No live APIs
- No automation
- No AI dependency for normal app use

## Learning Purpose

- Practice JavaScript web app fundamentals
- Learn how local JSON data drives a UI
- Understand basic filtering and selection flow
- Practice small, deliberate UI and animation choices
- Keep the project simple enough to finish and improve step by step
